# AI 코인 자동매매

바이낸스에서 코인을 자동으로 사고파는 프로그램을 단계별로 만드는 프로젝트입니다.

1. **전략 정하기 + 백테스트** (과거 데이터로 "이렇게 했다면 얼마 벌었을까" 시험)
2. **모의 투자** ← 지금 단계 (실제 돈 없이 실시간으로 돌려보기)
3. 소액 실전 투자

## 지금 들어 있는 전략: 변동성 돌파

하루에 한 번 이렇게 거래합니다 (바이낸스의 하루는 한국 시간 오전 9시에 시작).

1. **목표가** = 오늘 시작 가격 + k × (어제 최고가 − 어제 최저가)
2. 오늘 가격이 목표가를 넘으면 **산다**.
3. 다음 날 오전 9시(하루가 끝날 때)에 **판다**.
4. (선택) 최근 며칠 평균 가격보다 높을 때, 즉 오르는 추세일 때만 거래한다.

수수료(0.1%)와 체결 손해(0.05%)를 사고팔 때마다 빼고 계산합니다.

## 실행 방법

파이썬 3.10 이상이 필요합니다. API 키는 필요 없습니다 (공개 데이터만 사용).

```bash
pip install -r requirements.txt
python run_backtest.py              # 기본: BTC/USDT, 2018년부터, k=0.5
python run_backtest.py --k 0.4 --ma 5
python run_backtest.py --sweep      # 여러 설정을 한 번에 비교
python run_backtest.py --sweep --split 2023-01-01   # 2022년까지로 설정 고르고 2023년부터 검증
python run_split_trend.py                          # 분할 추세 전략(분할매수·손절·분할익절) 검증
```

결과 숫자 읽는 법:

| 항목 | 뜻 |
|---|---|
| 총수익률 | 처음 돈이 얼마나 늘었나 (100%면 두 배) |
| 연평균수익률(CAGR) | 1년에 평균 몇 % 늘었나 |
| 최대낙폭(MDD) | 가장 많이 잃었을 때 고점 대비 몇 % 빠졌나. 작을수록 마음 편함 |
| 승률 | 거래 중 돈을 번 거래의 비율 |
| 샤프지수 | 위험 대비 수익. 1 이상이면 괜찮은 편 |
| 단순보유 | 비교용: 첫날 사서 계속 들고 있었다면 |

## 코인 고르기 (참고용, 실전 사용 안 함)

바이낸스에서 지금 거래 중인 USDT 코인 500여 개를 훑어 "요즘 오르는 큰 코인"을 고릅니다 (`aicoin/rotation.py`).
상장 폐지된 코인과 스테이블코인, 레버리지 토큰은 뺍니다.

1. 상장 90일 넘은 코인 중 최근 30일 거래대금 상위 10개
2. 그중 50일 평균 위에 있는 코인
3. 최근 14일 상승률이 높은 순서로 5개를 골라 1/5씩 보유, 1주일마다 바꿈
4. 비트코인이 50일 평균 아래면 전부 현금. 코인 하나가 50일 평균 아래로 내려가면 그 코인만 팜

- **오늘의 순위표**: [`paper/PICKS.md`](paper/PICKS.md). GitHub Actions가 4시간마다 `python run_screen.py`로 갱신합니다.
- **검증**: `python run_rotation.py` (설정 44개를 2019~2022년으로 고르고 2023년~으로 시험)

| 2023년~ 시험 결과 (수수료 포함) | 총수익률 | 최대 손실폭 |
|---|---|---|
| 코인 고르기 (연습 기간 1등 설정) | +108% | -54% |
| 비트코인 분할 추세 (지금 모의 투자 중) | +239% | -27% |
| 비트코인 그냥 보유 | +383% | -53% |

44개 설정 중 비트코인 보유를 이긴 설정은 0개였습니다. 후보를 거래대금 상위 50~100개로 넓히면 -90% 넘게 잃었습니다.
2023년 이후엔 알트코인이 비트코인보다 계속 약했기 때문입니다. 그래서 순위표는 보기만 하고 돈은 넣지 않습니다.
(상장 폐지된 코인까지 넣어 시험해도 결과는 거의 같았습니다: `python run_rotation.py --include-delisted`)

## 모의 투자 (가상 $1,000)

분할 추세 전략을 가상의 $1,000로 2026-10-27부터 따라 합니다. 진짜 돈도, 바이낸스 API 키도 쓰지 않습니다.
설정이 다른 두 전략을 나란히 돌려 비교합니다 (`paper/config.json`).

| 전략 | 규칙 | 2023년~ 과거 시험 |
|---|---|---|
| 하루 단위 | 일봉 50개 평균 위면 매수, 손절 5%, 익절 20%/40% | +239%, 최대 손실폭 -27% |
| 4시간 단위 | 4시간봉 200개 평균 위면 매수, 손절 3%, 익절 20%/40% | +149%, 최대 손실폭 -31% |

(같은 기간 그냥 보유 +382%, 최대 손실폭 -53%. 1시간·15분 단위는 수수료 때문에 대부분 손해라 뺐습니다.)

- **현황 보기**: [`paper/STATUS.md`](paper/STATUS.md). GitHub Actions가 4시간마다 `python run_paper.py`를 돌려 저장합니다.
- **내 컴퓨터에서 실시간으로 보기 (윈도우)**
  1. https://www.python.org/downloads/ 에서 파이썬을 받아 설치합니다. 첫 화면 아래 **Add python.exe to PATH**에 체크하세요.
  2. 이 저장소 첫 화면의 초록색 **Code** 버튼 → **Download ZIP**으로 받고 압축을 풉니다.
  3. 압축 푼 폴더의 `start_live.bat`을 더블클릭합니다. 처음엔 설치에 몇 분 걸리고, 브라우저에 화면이 뜹니다. 검은 창을 닫으면 멈춥니다.

## 코인 분석 TF팀 (AI 8명, 참고용)

AI 8명이 팀처럼 회의해서 코인 하나하나에 매수/관망/매도 의견을 내고, TRAINER가 그 의견대로 모의투자를 합니다. 실제 돈은 넣지 않습니다.

| 팀 | 이름 | 하는 일 | 보는 자료 (모두 무료, 키 불필요) |
|---|---|---|---|
| 애널리스트 | TARO | 기술적 분석 | 바이낸스 일봉·4시간봉: MA20/MA60/MA120, 골든·데드크로스, RSI, 거래량, ATR |
| 애널리스트 | DIANA | 기본적 분석 | CoinGecko 시총·FDV·유통량, DefiLlama 체인 TVL |
| 애널리스트 | NOVA | 뉴스 분석 | CoinDesk·Cointelegraph·Decrypt 최근 3일 기사 |
| 애널리스트 | VIBE | 센티먼트 | 공포·탐욕 지수, 선물 펀딩비·롱숏 비율(바이낸스, 막히면 CoinGecko), 레딧 인기글, CoinGecko 투표·인기 검색 |
| 리서치 | BULL / BEAR | 매수 논거 vs 리스크, 2라운드 토론 | 애널리스트 보고서 |
| 수석 트레이더 | ACE | 최종 의견과 확신도 | 팀 전체 보고와 토론 |
| 모의투자 | TRAINER | 보고서 확실성을 매기고 ACE 결정대로 가상 매매 (확실성 높으면 최대 10배 레버리지) | 바이낸스 1시간봉, 결과는 [`paper/tf/trainer/TRAINER.md`](paper/tf/trainer/TRAINER.md) |

**돈이 들지 않습니다.** 역할을 둘로 나눴습니다.

1. **자료 모으기 (GitHub Actions, 무료)**: 매시간 20분에 바이낸스 전체 코인을 훑고 위 공개 자료를 모아 [`paper/tf/BRIEF.md`](paper/tf/BRIEF.md)에 저장합니다.
   Actions 탭의 **코인 분석 TF팀 자료 수집 → Run workflow**로 원하는 코인을 바로 모을 수도 있습니다.
2. **회의 (Claude 프로젝트 "코인 분석 TF팀" 안의 Claude)**: 그 자료를 읽고 [`aicoin/tf_team/PLAYBOOK.md`](aicoin/tf_team/PLAYBOOK.md) 순서대로
   7명 회의를 열어 [`paper/TF_REPORT.md`](paper/TF_REPORT.md)(최신)와 `paper/tf/날짜.md`(기록)에 보고서를 올립니다.
   Claude 구독 안에서 돌기 때문에 API 키나 추가 비용이 없습니다.

내 컴퓨터에서 자료만 모아 보려면:

```bash
pip install -r requirements-tf.txt
python run_tf_team.py                 # BTC, ETH → paper/tf/BRIEF.md
python run_tf_team.py BTC SOL XRP --print
```

(GitHub 서버는 미국에 있어 바이낸스 선물·레딧이 막힙니다. 그때 VIBE는 CoinGecko의 거래소별 펀딩비와 이용자 투표로 대신 봅니다.)

## 폴더 구성

- `aicoin/data.py` 바이낸스 과거 시세 내려받기
- `aicoin/strategy.py` 변동성 돌파 전략과 성적 계산
- `run_backtest.py` 실행 파일
- `run_paper.py` 모의 투자 실행 파일, `aicoin/paper.py` 모의 투자 계산, `paper/` 설정과 기록
- `live_paper.py`, `start_live.bat` 내 컴퓨터에서 보는 실시간 화면
- `run_tf_team.py`, `aicoin/tf_team/` 코인 분석 TF팀 (자료 수집 `sources.py`, 지표 `indicators.py`, 회의 자료 `brief.py`, 회의 진행표 `PLAYBOOK.md`)
- `tests/` 계산이 맞는지 확인하는 테스트 (`python -m pytest`)

> 백테스트 결과가 좋아도 미래 수익을 보장하지 않습니다. 실전 투자 전에 반드시 모의 투자를 거칩니다.
