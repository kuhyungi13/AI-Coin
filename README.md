# AI 코인 자동매매

바이낸스에서 코인을 자동으로 사고파는 프로그램을 단계별로 만드는 프로젝트입니다.

1. **전략 정하기 + 백테스트** ← 지금 단계 (과거 데이터로 "이렇게 했다면 얼마 벌었을까" 시험)
2. 모의 투자 (실제 돈 없이 실시간으로 돌려보기)
3. 소액 실전 투자

## 지금 들어 있는 전략: 변동성 돌파

하루에 한 번 이렇게 거래합니다 (바이낸스의 하루는 한국 시간 오전 9시에 시작).

1. **목표가** = 오늘 시작 가격 + k × (어제 최고가 − 어제 최저가)
2. 오늘 가격이 목표가를 넘으면 **산다**.
3. 다음 날 오전 9시(하루가 끝날 때)에 **판다**.
4. (선택) 최근 며칠 평균 가격보다 높을 때, 즉 오르는 추세일 때만 거래한다.

수수료(0.1%)와 체결 손해(0.05%)를 사고팔 때마다 빼고 계산합니다.

## 실행 방법

파이썬 3.10 이상이 필요합니다. API 키는 필요 없습니다 (공개 데이터만 사용).

```bash
pip install -r requirements.txt
python run_backtest.py              # 기본: BTC/USDT, 2018년부터, k=0.5
python run_backtest.py --k 0.4 --ma 5
python run_backtest.py --sweep      # 여러 설정을 한 번에 비교
python run_backtest.py --sweep --split 2023-01-01   # 2022년까지로 설정 고르고 2023년부터 검증
python run_split_trend.py                          # 분할 추세 전략(분할매수·손절·분할익절) 검증
```

결과 숫자 읽는 법:

| 항목 | 뜻 |
|---|---|
| 총수익률 | 처음 돈이 얼마나 늘었나 (100%면 두 배) |
| 연평균수익률(CAGR) | 1년에 평균 몇 % 늘었나 |
| 최대낙폭(MDD) | 가장 많이 잃었을 때 고점 대비 몇 % 빠졌나. 작을수록 마음 편함 |
| 승률 | 거래 중 돈을 번 거래의 비율 |
| 샤프지수 | 위험 대비 수익. 1 이상이면 괜찮은 편 |
| 단순보유 | 비교용: 첫날 사서 계속 들고 있었다면 |

## 폴더 구성

- `aicoin/data.py` 바이낸스 과거 시세 내려받기
- `aicoin/strategy.py` 변동성 돌파 전략과 성적 계산
- `run_backtest.py` 실행 파일
- `tests/` 계산이 맞는지 확인하는 테스트 (`python -m pytest`)

> 백테스트 결과가 좋아도 미래 수익을 보장하지 않습니다. 실전 투자 전에 반드시 모의 투자를 거칩니다.
